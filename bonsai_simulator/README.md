# 盆栽シミュレーター 技術コード抜粋

[ポートフォリオをで実際のプレイ画面を見る](https://lddos-san.github.io/games.html) ｜ [プレイ動画を見る](https://www.youtube.com/watch?v=Nwdavsh97pw&list=PLg_dwQJGlxvwXczsGahAcecXnoaELAmrG&index=9)

Unityで制作した盆栽育成ゲームから、枝の生成・編集・管理に関わる主要スクリプトを抜粋したリポジトリです。

ゲーム内では、プレイヤーが盆栽の枝を選択し、制御点を動かすことで形を編集できます。枝はあらかじめ用意したモデルではなく、制御点から曲線を作り、その周囲に頂点を配置して筒状メッシュとして生成しています。

## 概要

このゲームでは、盆栽の枝をプロシージャルメッシュとして生成しています。複数の制御点からCatmull-Romスプライン曲線を作り、曲線上にリング状の頂点を並べることで枝の形状を作成します。

枝の移動や成長では、メッシュの頂点を直接動かすのではなく、制御点を更新してメッシュを再生成しています。これにより、プレイヤーの編集操作や日付進行による成長に合わせて、枝の形を動的に変化させられるようにしました。

## 主な実装内容

- Catmull-Romスプライン曲線による枝の中心線生成
- 頂点、三角形、UVを自前で作成するプロシージャルメッシュ生成
- smoothstepによる自然な先端の細り
- 断面リングの向きを維持して、枝メッシュのねじれを抑える処理
- 親枝の曲線上の位置と接線方向を利用した枝分かれ生成
- 上方向へのバイアス、ランダムな曲げ、黄金角を使った自然な分岐表現
- 枝・葉オブジェクトの親子関係管理
- 親枝の曲線上のパラメータ`t`を使った子枝・葉の追従処理
- 制御点間距離を保った編集操作

## ファイル構成

```text
盆栽シミュレーター/
  BranchMesh.cs      // 枝メッシュ生成
  BranchGrower.cs    // 枝の成長・分岐・葉の生成
  TreeManager.cs     // 枝と葉の親子関係管理
  BranchSelector.cs  // 枝の選択・変形・削除操作
```

## 各スクリプトの役割

### BranchMesh.cs

枝の筒状メッシュを生成するスクリプトです。

制御点からCatmull-Romスプライン曲線を作り、その曲線上に円形の頂点リングを配置します。隣り合うリングを三角形でつなぎ、Unityの`Mesh`として反映しています。

先端は`smoothstep`で自然に細くし、断面リングの向きは前回の上方向を使ってねじれを抑えています。また、生成したメッシュを`MeshFilter`に設定し、同じ形状を`MeshCollider`にも反映することで、描画と当たり判定の両方に使えるようにしています。

### BranchGrower.cs

日付進行に合わせて枝を伸ばしたり、新しい枝や葉を生成したりするスクリプトです。

新しい枝を作るときは、親枝の曲線上の座標と接線方向を参照しています。さらに、黄金角で分岐方向を散らし、上方向への補正やランダムな曲げを加えることで、枝が機械的に増えるのではなく、自然に広がるように調整しました。

枝の太さと長さは親枝を基準に決め、親より太くなりすぎたり長くなりすぎたりしないようにしています。成長時は枝全体を拡大するのではなく、末端方向に新しい制御点を追加して伸ばしています。

### TreeManager.cs

木全体の構造を管理するスクリプトです。

枝と葉をリストで管理し、それぞれの親子関係や接続位置を保持しています。枝の削除時には、子枝や葉もまとめて削除されるようにし、木構造が途中で壊れないようにしています。

また、親枝が移動・変形したときに、子枝や葉が親枝上の位置に追従する処理も担当しています。

### BranchSelector.cs

プレイヤーが枝を選択し、制御点を動かして形を編集するためのスクリプトです。

枝を選択すると制御点が表示され、選択した制御点をドラッグすると、その位置に合わせて枝メッシュを再生成します。ドラッグ時は元の制御点間距離を超えないようにし、後ろの制御点も一緒に動かすことで、枝先の形が崩れにくいようにしています。

制御点の移動後は、子枝や葉の位置も更新し、編集後も全体の形が破綻しないようにしています。

## 工夫した点

枝や葉の位置を単なるワールド座標だけで管理すると、親枝を変形したときに子要素がずれてしまいます。そのため、子枝や葉の接続位置を親枝の曲線上のパラメータとして保持し、親枝の形が変わったあとも位置を再計算できるようにしました。

また、成長時には枝全体を単純に拡大するのではなく、末端方向に新しい制御点を追加してメッシュを再生成しています。これにより、枝が伸びていく見た目を自然に表現できるようにしました。

枝メッシュの生成では、断面リングを曲線に沿って並べるだけでなく、前回の上方向を使ってリングの向きを決めています。これにより、曲線が曲がったときの断面のねじれを抑えています。
