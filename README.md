# コード公開リポジトリ

就職活動用に、制作物の中から技術的に説明しやすいコードを抜粋してまとめたリポジトリです。

各フォルダには、作品ごとの主要コードと実装内容の説明を置いています。

## 掲載コード

### 盆栽シミュレーター

Unityで制作した盆栽育成ゲームのうち、枝の生成・編集・管理に関わるコードを掲載しています。

- Catmull-Romスプライン曲線による枝形状生成
- 頂点、三角形、UVを自前で作成するプロシージャルメッシュ生成
- 黄金角、上方向バイアス、ランダム曲げによる分岐表現
- 枝・葉オブジェクトの親子関係管理
- 親枝の曲線上パラメータを使った子枝・葉の追従処理

詳細は[盆栽シミュレーター/README.md](./盆栽シミュレーター/README.md)に記載しています。
